What is new

机械臂更多，时间更长，世界从不等人。

以往的 benchmark 只给 agent 一到四条机械臂，任务大多几分钟就结束；不少还会在 agent 思考时暂停仿真，或者干脆把每个物体的位置告诉它。这三样便利，RoboTeam 一样也不给。

  • 最多 16 条机械臂，最长 24 小时

    每个任务由 4 到 16 条机械臂一起完成，一次运行可以持续一整天。

  • 一刻不停

    厂房实时运转，agent 想得再久，它也不会停下来等。只有 agent 宣布完成，或者干满 24 小时，运行才会结束。

  • 只给相机，不给捷径

    不给物体位置，也不给深度，一切都得 agent 从画面里自己估。它们宣布完成后，由一个它们碰不到的评估程序直接检查仿真世界。

The four jobs

单靠一条机械臂干不了的活。

每类任务都分三种团队规模、三个难度，一共 36 个任务。每段视频都是 gpt-6.1-sol 的真实运行，按 300× real time 播放。鼠标移到团队规模或难度上即可切换，点开视频能看完整过程。

How a run works

拆开一次真实运行看看。

agent 干活就是一个循环：看相机、拿主意、给一条机械臂下一道命令，然后再看。来看 gpt-6.1-sol 的一次运行：8 条机械臂的 Transport 任务，最后 24 件物品全部到位。

  1. 1

    See

    只有画面

    每条机械臂都装有相机。画面里不带任何坐标，位置全靠 agent 自己算。

  2. 2

    Decide

    分工

    运行刚开始，controller 就叫来一个 helper，分给它两条机械臂。

    “Deliver one yellow source C cube into B_slot2, seated released stable, using B/C …”

    controller 对新 helper 说
    • 2条机械臂交给它：B 和 C
    • 24个动作，全由 helper 完成
    • 7.8分钟后交回机械臂
  3. 3

    Act

    一道命令，一条机械臂

    每个动作就是调用一次 robot tool，调用时还可以要求动作结束后回传一张新画面。

    agent 发出move arm A to (−0.107, −0.973, 0.95) m at 0.12 m/s, then show camera A_front
    robot tool 回复

    Completed，并回传 A_front 的新画面

  4. 4

    Check

    看出问题，再来一次

    后来，另一个 helper 用 Arm C 去抓，夹爪合到 0.065 m 就停了，没到预期的 0.06 m。没有任何提示说哪里出了错，agent 看了看画面，又试了一次。

    agent 发出grasp with arm C, expecting 0.06 m, then show C_front and C_side
    robot tool 回复

    Grasp stopped outside expected object-width tolerance

Results

难就难在看。

只靠相机，最强的 AI 团队完成了大部分任务；如果直接给出每个物体的 ground-truth position，同一个 AI 就全部完成了。

What we learned

从运行里看到的五件事。

最强的团队完成了大部分任务。可它是怎么做到的、其他团队又输在哪里，比分数本身更能说明 AI 在物理世界里的真实水平。
