# Relay

团队要沿着一串工作台面，把红色木料从起始位置运到画好的 GOAL 区。木料长约 1.2 m；8、12、16 条机械臂分别对应 2、3、4 根。在空中搬一根木料至少要两条机械臂，而且每根木料至少要有一次合格的空中交接才算数。木料在 GOAL 里怎么放都行，可以互相碰着，也可以叠起来。

| 难度 | 木料 |
| --- | --- |
| 1（`l1`） | 直木料 |
| 2（`l2`） | 63° 的圆弧木料，底下吊着一个能自由摆动的重物（170 mm 长的木杆，600 g） |
| 3（`l3`） | 31.5° 的折角木料（内角 148.5°），带面外方向的被动弹簧（±25°），下面吊着同样的重物 |

| 机械臂 | 布局 | 木料 |
| --- | --- | --- |
| 8 | 两排直线 | 2 |
| 12 | 90° 圆弧，外圈 7 条、内圈 5 条机械臂 | 3 |
| 16 | 半圆，外圈 10 条、内圈 6 条机械臂 | 4 |

桌高 0.8 m。机械臂只能抓红色木料，不能抓吊着的重物，也不能抓它的吊环和木杆。

和 Transport 一样，公开任务在 `static_camera_mounts` 里列出每台相机在世界里的固定位置、`wxyz` 朝向和垂直视场角。

<a id="completion"></a>
## 完成条件

评分时，一根木料要同时满足下面三条才算完成：

- 中心线至少有 70% 的长度落在 GOAL 轮廓正上方的竖直空间里（`relay-timber-goal-70pct-v1`；只算木料本身，吊着的重物不算），这个比例记在 `timber_inside_fraction`；
- 所有机械臂都已松手；不要求有桌面托着，也不要求静止；
- 它有一次算数的空中交接（`relay-airborne-handover-v1`），记在 `airborne_handover_met`。

所有木料都完成，任务才算完成。阈值在公开任务的 `completion` 块里（`timber_inside_fraction_min: 0.7`、`required_airborne_handover: true`）。`roboteam/tasks/relay_goal_fraction.py` 计算这个比例；`roboteam/tasks/evaluate.py` 里的 `Relay` 类记录每根木料由谁抓着、交接过几次、掉过几次。

<a id="handovers"></a>
## 交接

- **空中。** 至少两条机械臂抓着木料、把它抬高超过 25 mm，木料就算在空中。木料最低处离桌面超过 2 mm，并且不直接、也不经由其他货物和桌面相连，就算*离桌*。
- **合格的交接。** 木料离桌、当前至少有两条机械臂抓着时，一条新的机械臂必须抓住它，保持至少 0.2 秒；然后原来抓着的一条机械臂松手。这次换手记为 `protocol: qualified-members-v3`、`airborne: true`。只要木料碰到桌面，或者接手的机械臂失去接触，这 0.2 秒就从头计。新机械臂还没达标就换了手，会记一次 `unverified_handover` 违规，这次换手不算数。
- **不算交接。** 在桌面上推或拖木料；木料停在 GOAL 里时换手（记为 `grounded-regrasp-v1`、`airborne: false`）。

<a id="drops-and-recovery"></a>
## 掉落和恢复

空中的木料在 GOAL 允许落下的范围以外碰到桌面或地面，或者抓着它的机械臂不足两条超过 0.2 秒，就算*掉落*。掉落次数记在 `drops` 里，也作为过程事件记下，但不会推翻分数。

- 木料掉下时抓着它的那些机械臂，可以把它重新抬起来。只要其中至少两条把它抬离桌面，它就又回到空中，之前的交接照样算数。
- 如果别的机械臂去抓这根掉下的木料，会记一次 `receiver_recovered_drop` 违规。这时这根木料的交接，不论之前还是之后的，都不算数，直到掉落时抓着它的那些机械臂再把它抬离桌面；只有这次抬起之后的交接才算数。

续跑的运行会保留每根木料停下那一刻的交接、掉落和抓着它的机械臂（[续跑停下的运行](../../runs/continuation.md#known-approximations)）。
