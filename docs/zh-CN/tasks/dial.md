# Dial

每个拨盘模块有一个旋钮，旋钮上有六个刻度（0–5，每格 60°），还对应一个藏起来的密码数字，取值 1–5。团队要把每个旋钮都拧到一个非零刻度，并让它们同时停住。面板上的 BEST 数字显示：本 episode 里，单次完整、有效的输入最多对过几个拨盘；它从不显示当前对了几个。READY 显示当前输入是否有效。只要有一次有效输入全对，这个 case 就算解开。

| 难度 | 模块 | 机械臂（4、6、8 个拨盘） |
| --- | --- | --- |
| 1（`l1`） | 齿轮拨盘固定在桌上 | 4、6、8 |
| 2（`l2`） | 模块不固定：每个模块由一条机械臂抓住蓝色把手，托到离所有支撑至少 20 mm 的地方，另一条机械臂同时拧红色旋钮 | 8、12、16 |
| 3（`l3`） | 同 Level 2，但要用单侧曲柄来拧，弹簧也更硬 | 8、12、16 |

桌高 0.8 m，每个白色圆盘直径 0.3 m。桌面轮廓、底座、面板和相机，都写在每个 case 的公开任务和任务类型材料（预览图、相机标定、`table-geometry.json`）里。

<a id="the-code"></a>
## 密码

每个 case 的密码是固定的：密码存在 `benchmark/release.json` 的 `private.dial_codes` 里，这个 case 的每次 policy 运行都用同一组密码。密码只有评分程序能看到，从不复制进运行的公开文件。刻度 4 和 5 也可以在 −120° 和 −60° 处拧到；±180° 是刻度 3。

<a id="feedback-and-completion"></a>
## 反馈和完成条件

一次**有效输入**要满足：每个拨盘都在某个非零刻度的 4° 以内；每个红色旋钮（Level 3 是曲柄握把）都有一条机械臂抓着；Level 2 和 3 还要另一条机械臂把模块托离支撑；以上状态在仿真时间里稳定保持 0.25 秒。

| 信号 | 含义 |
| --- | --- |
| READY 灰色 | 当前输入无效（没对准刻度、拧在零、少了抓取或托举） |
| READY 琥珀色 | 有效，还在确认中 |
| READY 绿色 | 已经有效了 0.25 秒；这次输入算一次尝试，会更新 BEST |
| BEST | 从 0 开始；只在 READY 为绿色时亮，其余时候是暗的；数值没变，可能是一样好，也可能更差 |

每出现一个新的、稳定的有效配置，就算一次尝试，运动途中经过的也算。**成功会锁定**：只要有一次有效输入全对，这个 case 就算解开，之后再怎么拧拨盘也不会撤销。解开之前的碰撞和失去支撑，仍作为过程事件记录在案。反馈的状态机在 `roboteam/tasks/dial.py` 里；输入是否有效，由 `roboteam/tasks/evaluate.py`（`sample_dial`）判断。
